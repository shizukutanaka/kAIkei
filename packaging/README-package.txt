kAIkei（個人用単体パッケージ）のつかいかた
==========================================

これは kAIkei を自分のパソコンだけで使うためのパッケージです。
サーバも Docker もデータベースのインストールも要りません。
データはこのフォルダの中（data フォルダ）にだけ保存されます。


起動のしかた
------------
1. START-KAIKEI.bat をダブルクリックします。
2. 黒い窓が開き、しばらくするとブラウザで kAIkei の画面が開きます。
   （黒い窓が kAIkei 本体です。使っている間は閉じないでください）
3. やめるときは、黒い窓を閉じます。


最初の1回だけ（アカウント作り）
--------------------------------
初めて起動すると「初回設定」の画面が開きます。

1. メールアドレス・パスワード・表示名を入れます。
   「組織コード」は自分のための目印なので、初期値（personal）のままで
   構いません。
2. 「アカウントを作る」を押すとログイン画面に移ります。
   いま入れたメールアドレスとパスワードでログインしてください。
3. ログインしたら、まず会社を作ります（画面の会社切替のところにある
   「会社を作成」から）。
4. 次に「科目マスタ」の画面で「標準科目セット」を押して、勘定科目の
   初期セットを入れます。

ここまで終われば準備完了です。2回目からは起動してログインするだけです。


ふだんの流れ（銀行明細から仕訳へ）
----------------------------------
1. 銀行のサイトから入出金明細の CSV をダウンロードします。
2. kAIkei の「銀行」画面でその CSV を取り込みます。
   （文字コードは自動で判別します。取り込めなかった行は理由つきで
   表示されます。黙って消えることはありません）
3. 明細ごとに「仕訳化」を押すと、過去の仕訳から学習した相手科目の
   候補が出ます。確認・修正して確定してください。
   確定した仕訳は次回からの学習に使われます。
4. 「仕訳」画面の書き出しから「弥生形式」を選ぶと、弥生会計に
   取り込めるファイルが出力されます。


データとバックアップ
--------------------
- データは data フォルダの中の kaikei.db というファイル1つです。
- バックアップは、kAIkei を止めた状態で data フォルダごと
  コピーするだけです。戻すときは data フォルダを元に戻します。
- data フォルダにはログイン用の秘密鍵（.jwt_secret）も入っています。
  バックアップと一緒に保管してください（他人には渡さないこと）。


困ったとき
----------
- 起動しない・途中で止まった場合は、同じフォルダにある
  kaikei-run.log に理由が残っています。
- 画面が開かない場合は、黒い窓に表示される
  「起動しました: http://127.0.0.1:（数字）/」のアドレスを
  ブラウザに直接入力してください。
- ポート 8000 が他のアプリと重なった場合は、自動で次の番号に
  ずらして起動します（アドレスの数字が変わります）。


入っているもの
--------------
- START-KAIKEI.bat … 起動用ファイル
- launch.py ……… 起動スクリプト（ポート確認・ブラウザ起動）
- runtime/ ……… 同梱の Python 実行環境（インストール不要）
- server/ ………… kAIkei 本体（バックエンド）
- web/ …………… 画面一式
- data/ ………… あなたのデータ（起動すると作られます）
